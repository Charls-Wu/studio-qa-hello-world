# Hello World QA demonstration

This repository is a minimal application for validating Studio task coordination.
Run `node main.mjs`. Keep the exact output required by the Studio issue, including casing.
Use Node.js built-ins only; no dependencies or deployment required.
QA standards and test scripts belong in the separate test working directory of the Studio project.
Do not change test expectations without pointing to the explicit requirement. Leave human acceptance to the owner.
Write commits and pull requests in English. Do not merge pull requests or accept tasks yourself.
